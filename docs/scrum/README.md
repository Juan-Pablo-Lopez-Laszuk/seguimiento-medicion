# Scrum

Cada sprint dura **una semana** (lunes a domingo) y guarda sus registros en `docs/scrum/sprint-N/`:

| Archivo | Ceremonia | Cuándo |
|---|---|---|
| `planning.md` | Sprint Planning | Lunes, 1 h |
| `dailies.md` | Daily | Lunes a viernes, 10 min (puede ser por mensaje) |
| `review.md` | Sprint Review | Fin de la semana, con el profesor |
| `retro.md` | Retrospective | Después de la Review |

Las plantillas están en [`_plantillas/`](_plantillas/). El Agile Enabler (Juan Pablo) facilita las ceremonias y sube las actas.
